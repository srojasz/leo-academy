# ⚽ Leo Academy

Web para repasar las asignaturas de 5º de primaria jugando, con ambientación de fútbol.

- **Abrir en local:** doble clic en `index.html` (funciona sin instalar nada).
- **En la tablet:** abrir la dirección publicada en Safari/Chrome → Compartir → *Añadir a pantalla de inicio*. Así se abre como si fuera una app.
- **Probar:** `tools/test.sh`
- **Cómo se añaden unidades y asignaturas:** ver `CLAUDE.md`.

El progreso (goles, estrellas y cromos) se guarda en cada dispositivo por separado.
